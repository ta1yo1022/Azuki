# Azuki運営の単語帳 — 500語・全語例文付き（第3版）

EJDict（英和辞書 ejdict-hand）から見出し語と語義を抽出し、5テーマに編集した単語帳です。各500語・合計2,500件。各単語帳内の見出し語は重複せず、テーマ間では一部共通する語があります（全体の異なり語数は2,323）。日本語の意味はテーマに合う語義に絞って整理し、必要に応じて現代の用法を補っています。

各500語すべてに英語の例文を収録しています。第3版では、初回版の250例文を保持して、残り2,250語に例文を追加しました。各例文は登録済みの日本語訳・品詞・テーマに合う短い英文をAzuki向けに作成したもので、EJDictからの引用ではありません。

## レベルと運営表示

レベルは単語帳全体の語彙の広さ・専門性をもとにしたAzuki独自の目安です。教材・試験・CEFRとの公式な対応を示すものではありません。

- 初級：身近な場面で使う基本の語彙。旅行は場所、移動、買い物など具体的な場面を中心に選定。
- 中級：基本の語彙から、表現の幅や意味の使い分けを広げる。動詞・感情表現の細かな区別、食材や調理の語彙を含む。
- 上級：専門的・抽象的な場面の語彙。仕事では契約、会計、組織運営なども含む。

一覧の表紙と詳細に「Azuki運営 発行」を表示し、レベルは運営の単語帳だけに表示します。一般ユーザーの単語帳や保存したコピーには付けません。

- ライセンス原文：`EJDict-LICENSE.txt`
- `manifest.json`：版番号、各単語帳のレベル、取得日時、固定コミット、元ファイルと単語帳のSHA-256
- `source-entries.json`：全2,500件の元の見出し語・語義・ファイル・行番号と採用した意味。原文の古い記法や複数の語義も残す監査用データで、アプリには配信しません。
- `editorial-overrides.json`：テーマに合わせた日本語の語義の補足・修正。
- `releases/v1/`：初回版のマニフェストとシード。更新テスト用に保持。
- `releases/v2/`：500語版・例文補完前のマニフェストとシード。例文だけの更新で語数が二重計上されないことの検証に使用。

単語帳JSONにはアプリのインポート形式だけを含めています。JSONからは運営表示・レベル・出典メタデータを付与できません。アプリの「自分の単語帳に保存」では、出典情報を引き継ぎます。保存したコピーは独立しており、運営の新版への自動追従はしません。

## GitHubのPRで編集する

運営の原本はD1ではなく、このリポジトリのJSONで管理し、Cloudflare Pagesから配信します。ユーザーの単語帳・フォーク・保存済みコピー・通報はD1に残ります。

1. `decks/*.json`で単語・意味・例文、タイトルや説明を編集します。レベルは`manifest.json`の該当する`level`を編集します。公開IDは変更しません。
2. CEFR-Jの場合は`../cefrj/editorial/*.json`を編集します。詳しくはそちらのREADMEを参照してください。
3. `npm ci`、`npm test`、`npm run build`を実行します。生成処理はテストとビルドの前に自動で実行されます。
4. 変更理由と、語義・例文を確認した根拠を添えてPRを作成します。PR上のCIが形式・テスト・ビルドをチェックし、mainへのマージ後に既存のCloudflareワークフローが配信します。

`public/content/`と`shared/*-catalog.json`は生成物です。編集元のJSONを修正してください。配信用ファイル名には内容ハッシュを含め、フォーク時の比較用ハッシュも自動で更新します。形式の検証だけでは意味の正確さは保証できないので、PRレビューで確認してください。

`manifest.json`の既存SHA-256・語数・タイトルは第3版の取得記録です。現在の配信メタデータはJSONから生成します。`seed.sql`、`releases/`、旧シード生成スクリプトは移行テストの履歴資料で、運用には使用しません。DB登録用のnpmコマンドは廃止しました。

移行`0012_official_static_content.sql`は予約所有者の既存5冊だけをD1から削除します。ユーザーのコピーや通報は削除しません。共有URLは同じIDの静的原本を開き、保存済みコピーは引き続き独立したデータとして保持します。運営原本の修正はコピーへ自動反映されません。

## 例文の日本語訳

各単語の `examples: [{"text":"英文","translation":"日本語訳"}]` に例文の日本語訳を保存します。従来の `example` は同じ英文のまま保持し、一覧・本型表示・例文カード・フォークで共通して利用します。全2,500項目の訳を必須とし、ビルド時に訳抜けを検出します。

翻訳モデルの下訳と編集によって作成しています。全文の専門家による校閲を受けたものではありません。[作成記録](../../docs/example-translations.md)も参照してください。修正はこのJSONの `translation` へPRを送ってください。既に保存された個人のコピーは自動更新しません。
