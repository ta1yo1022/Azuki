# Azuki運営の単語帳 — 500語・全語例文付き（第3版）

EJDict（英和辞書 ejdict-hand）から見出し語と語義を抽出し、5テーマに編集した単語帳です。各500語・合計2,500件。各単語帳内の見出し語は重複せず、テーマ間では一部共通する語があります（全体の異なり語数は2,323）。日本語の意味はテーマに合う語義に絞って整理し、必要に応じて現代の用法を補っています。

各500語すべてに英語の例文を収録しています。第3版では、初回版の250例文を保持して、残り2,250語に例文を追加しました。各例文は登録済みの日本語訳・品詞・テーマに合う短い英文をAzuki向けに作成したもので、EJDictからの引用ではありません。

## レベルと運営表示

レベルは単語帳全体の語彙の広さ・専門性をもとにしたAzuki独自の目安です。教材・試験・CEFRとの公式な対応を示すものではありません。

- 初級：身近な場面で使う基本の語彙。旅行は場所、移動、買い物など具体的な場面を中心に選定。
- 中級：基本の語彙から、表現の幅や意味の使い分けを広げる。動詞・感情表現の細かな区別、食材や調理の語彙を含む。
- 上級：専門的・抽象的な場面の語彙。仕事では契約、会計、組織運営なども含む。

一覧の表紙と詳細に「Azuki運営 発行」を表示し、レベルは運営の単語帳だけに表示します。一般ユーザーの単語帳や保存したコピーには付けません。

- 元の辞書データのライセンス：[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/deed.ja)
- ライセンス原文：`EJDict-LICENSE.txt`
- `manifest.json`：版番号、各単語帳のレベル、取得日時、固定コミット、元ファイルと単語帳のSHA-256
- `source-entries.json`：全2,500件の元の見出し語・語義・ファイル・行番号と採用した意味。原文の古い記法や複数の語義も残す監査用データで、アプリには配信しません。
- `editorial-overrides.json`：テーマに合わせた日本語の語義の補足・修正。
- `releases/v1/`：初回版のマニフェストとシード。更新テスト用に保持。
- `releases/v2/`：500語版・例文補完前のマニフェストとシード。例文だけの更新で語数が二重計上されないことの検証に使用。

単語帳JSONにはアプリのインポート形式だけを含めています。JSONからは運営表示・レベル・出典メタデータを付与できません。アプリの「自分の単語帳に保存」では、出典情報を引き継ぎます。保存したコピーは独立しており、運営の新版への自動追従はしません。

## 登録・更新

プロジェクト直下で、マイグレーション（0006まで）を先に適用します。

```sh
npm run db:local
npm run content:local
```

本番は、ログイン済みのCloudflareアカウントで実行します。

```sh
npm run db:remote
npm run content:remote
```

`content:build`は共通のJSON検証に加え、各500語・全体2,500件・単語帳内の重複・全語の例文・出典・ハッシュを検証して`seed.sql`を生成します。第3版シードは初回登録・既存50語版・500語版の更新に対応し、共有IDと作成日時を維持します。更新対象は予約所有者・出典・版番号が一致する5冊だけです。ユーザーの単語帳や保存済みコピーは変更しません。

D1のリモートSQLファイル取り込みは全体が一括で成功・失敗します。SQLファイルにBEGIN/COMMITを追加しないでください。ローカル単体テストでは明示的なトランザクションで失敗時の復元も検証します。500語が揃った単語帳にだけ版番号3と公開状態を設定します。再実行時は適用済みの単語帳をスキップし、利用量も二重加算しません。

所有者`azuki:official`はDB管理専用で、このIDによるAPI操作は禁止しています。運営表示は所有者からサーバー側で判定します。レベルもこの所有者の値だけを返し、JSONの偽装値は取り込みません。コピーには`content_source`を引き継ぎ、原本削除後も出典を表示できます。

増えた語数・容量はDBのトリガーで集計します。500語版からの例文追加では語数・日次登録語数は増やさず、例文で増加した容量だけを加算します。運営の登録のみ一般利用者の1日1,000語上限から除外し、全体の1日5,000語・合計100,000語・100MiB上限と所有者ごとの5,000語・20冊上限は維持しています。今後の版はマニフェスト・生成スクリプト・更新テストを合わせて変更してください。
