# 単語貼り付け用の英和辞書

EJDict（CC0 1.0）の固定コミット `9663055d59a8cb1a35078a71db7a09ff39305828` を使用します。取得済みの公式単語帳と同じ原典です。

- 原典: https://github.com/kujirahand/EJDict
- `source/`: 取得した26個の辞書テキスト。
- `assets/`: `node scripts/build-dictionary.mjs` で作成するWorker用の検索データ。
- `manifest.json`: 原典・版・件数・各配信ファイルのハッシュ。
- `LICENSE.txt`: 原典のCC0ライセンス。

見出し語の大文字小文字・空白・引用符を正規化し、カンマで併記された見出し語を展開します。語義は原典の ` / ` 区切りを保持し、強調用の『』だけを除きます。600文字を超える語義、英語の通常の見出し語として扱えない項目を除き、1語につき最大30語義を配信します。AIは意味を書き換えません。複数の語義から利用者が選べます。

原典には古い語法や表記が含まれます。辞書・生成例文とも確認・編集を経て登録します。AIの例文・日本語訳はこの辞書の引用ではありません。
