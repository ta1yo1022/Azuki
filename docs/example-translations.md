# 標準単語帳の例文の日本語訳

## 対象・保存場所

2026年10月19日、運営発行の13冊・10,301項目に、既存の英文例文に対応する日本語訳を追加しました。対象はテーマ別5冊・2,500項目、CEFR-J A1〜B2の8冊・7,801項目です。同一英文は訳の一貫性のため共通の下訳を使っています。

- テーマ別：`content/official/decks/*.json` の `examples[].translation`
- CEFR-J：`content/cefrj/editorial/*.json` の `exampleTranslation`
- 配信データ：`examples: [{text, translation}]`。従来の単一英文 `example` も保持

既存の見出し語・品詞・掲載順・意味・英文例文・公開IDは変更していません。個人が保存・編集した単語帳を更新するD1の操作は行いません。最新の標準単語帳を開くと新しい訳を使えます。例文カード、一覧、本型表示、今後の保存・フォークで同じ日本語訳を参照します。

## 下訳と確認

下訳には Google MADLAD-400-3B-MT をローカル実行して使用しました。翻訳処理のためにユーザーの個人データや非公開の単語帳を送信していません。モデルの重みはリポジトリやアプリには同梱しません。アプリの実行時に翻訳サービスを呼び出す仕組みではありません。

- 原モデル：[google/madlad400-3b-mt](https://huggingface.co/google/madlad400-3b-mt)、revision `fa184c675da0b5c9e1c8694fccd4e12e2d422094`
- 使用した量子化モデル：[Nextcloud-AI/madlad400-3b-mt-ct2-int8](https://huggingface.co/Nextcloud-AI/madlad400-3b-mt-ct2-int8)、revision `aa32bbdeba7880eff2096ec044cb155a340a9400`
- モデルの公開ライセンス：Apache-2.0
- 処理：CTranslate2、英語→日本語、greedy decoding。推論結果に対する編集・修正を実施

初回の反映では8,870種類の英文を対象とし、うち810種類の訳を個別に作成・修正しました。各冊の冒頭、下訳のスコアが低い箇所、意味の取り違え・訳抜けが疑われる箇所などを確認し、必要な修正を加えています。例えば delivery の「配達／出産」、debit の「借方」、stale の「新鮮でない」など、登録された単語の意味に合うように調整しています。全文を専門家が校閲したものではなく、誤りが残る可能性があります。CEFR-Jの公式訳・公式例文ではありません。

## 修正・検証

訳の修正は上記の編集元にPRを送ってください。既存の英文に合う訳を入力し、独自の英文に置き換える場合は日本語訳も同時に見直してください。辞書や教材の訳文をそのまま転載せず、必要な権利を確認してください。

`npm test`・`npm run build` は訳抜け・日本語を含まない訳・上限を超える訳を拒否し、全項目が配信データに引き継がれることと、大きな単語帳も翻訳を保ったままフォークできることを確認します。自動チェックは意味の正確さを保証するものではありません。

原典の出典・利用条件は従来どおりです。[CEFR-J](../content/cefrj/README.md)、[EJDict由来のテーマ別単語帳](../content/official/README.md)、[ライセンスの適用範囲](../THIRD_PARTY_NOTICES.md)を参照してください。
