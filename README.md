# Azuki

React + TypeScript + Vite / Cloudflare Pages + Workers + D1 / Firebase Authenticationで作る英単語帳です。

本番URL: **https://azuki.mame-app.com**

2026年10月5日にWorker・Pagesを公開し、D1の保存テーブルを作成しました。Firebase側の本番ドメイン登録とGoogle認証開始APIの正常応答も確認済みです。実Googleログイン後の保存確認は[SETUP.md](SETUP.md)を参照してください。

## 初期版でできること

- 小豆色と丸い書体のトップページ。3語のめくれるカード、機能紹介、サンプル単語帳への入口

- JSONファイルの選択・ドラッグ＆ドロップ・貼り付け、登録前プレビュー
- 単語帳の一覧、教材タグでの絞り込み、英単語・日本語の意味の検索、例文の表示
- 1語ずつカードで学習。タップで意味・例文を表示、前後に移動、最後まで進んだら再スタート
- 教材名・版・章の取り込み。単語ごとのタグとは別に管理
- 単語帳の削除、非公開での保存
- 単語帳の公開・非公開の切り替え、共有リンクのコピー
- 運営作成の公開単語帳5冊・各500語（合計2,500語）。「Azuki運営 発行」の表示、運営の単語帳だけに初級・中級・上級の目安、EJDictの出典表示
- ログインなしで公開単語帳を検索・閲覧（単語帳名・説明・教材タグで検索）
- 公開単語帳を自分専用の非公開コピーとして保存（Googleログインが必要）
- 一覧・詳細・学習・共有・追加のURLルーティング。再読み込みと戻る・進むに対応
- アカウント作成前に使えるお試しモード（この端末のブラウザにのみ保存）

本番はFirebase AuthenticationとCloudflare D1に接続する設定で公開済みです。実Googleログイン完了と端末間同期の確認は未実施です。お試しデータはGoogleアカウントへ自動で移されません。

## ローカルで試す

Node.js 22.22.3以上の22系を推奨します。プロジェクトのフォルダで実行してください。

```sh
npm ci
npm run dev
```

- ログイン画面: http://127.0.0.1:5173/
- お試しモード: http://127.0.0.1:5173/demo

お試しモードにサンプル3冊・36語が入ります。通常モードのアカウントにはサンプルを追加しません。

## JSON形式

```json
{
  "schemaVersion": 1,
  "title": "日常英単語",
  "description": "授業で出会った言葉",
  "textbookTags": [
    { "name": "英語の教科書", "edition": "第2版", "chapter": "Lesson 1" }
  ],
  "words": [
    {
      "word": "accomplish",
      "meaning": "達成する",
      "example": "We accomplished our goal.",
      "tags": ["動詞"]
    }
  ]
}
```

必須は`title`、`words`、各単語の`word`と`meaning`です。`schemaVersion`を省略した既存の形式も利用できます。`description`、`textbookTags`、`example`、`tags`は任意です。所有者や公開状態がJSONに含まれていても取り込みません。必ずログインした本人の非公開単語帳になります。同じ単語でも意味が違えば登録できます。

## 初期版の上限

| 項目                           | アプリで設けている上限         |
| ------------------------------ | ------------------------------ |
| 1回の取り込み                  | 500語・512KB                   |
| 1人分                          | 20冊・合計5,000語              |
| 1人の1日の登録数               | 5,000語                        |
| 全体の1日の登録数              | 10,000語                        |
| 全体の保存語数                 | 100,000語                      |
| 全体の取り込み済みJSON相当容量 | 100MiB（索引などの余裕を確保） |
| 単語の1回の取得                | 50語                           |

運営のDB管理による登録・増量のみ、1人の1日の登録数から除外します。全体の上限には含めます。

日次上限はUTCの0時（日本時間9時）に切り替わります。削除しても当日の登録数は戻しません。DBのトリガーで同時登録時にも上限を守り、途中で失敗したインポートはまとめて取り消します。

これらは無料枠の消費を抑える初期設定であり、無料枠内の無停止運用を保証する値ではありません。D1の実容量・読み書き、Workersのリクエスト数・CPU上限は別に適用されます。容量はCloudflareでも確認してください。`ALLOW_IMPORTS=false`で新規取り込み・新しいコピーの保存を止め、登録済み単語帳の閲覧を継続できます。Cloudflare Free側の上限に達した場合は、該当処理が失敗します。

## カードで学習する

単語帳を開いて **カードで学習** を選ぶと、全画面の学習ページに切り替わり、1語ずつ表示します。初期設定は「順番どおり」「日本語 → 英語」です。カードをタップすると答え・例文・単語タグが見えます。画面上部で「シャッフル」「英語 → 日本語」に切り替えられます。日本語が表のときは英単語・例文を隠します。カードは表裏とも同じ縦横サイズで、長い内容はカード内をスクロールして読めます。**前の単語 / 次の単語**、または左右キーで移動でき、カードにフォーカスした状態でEnter・Spaceを押してもめくれます。**単語一覧に戻る** またはEscで一覧に戻ります。最後のカードの **学習を終える** から、もう一度はじめることもできます。

お試しモードと公開単語帳でも利用できます。カード学習の対象は単語帳全体です。検索による絞り込みは一覧表示に適用されます。順番どおりの場合は単語を50語ずつ必要になったときに読み込みます。シャッフルは全ページを読み込んでから全体を並べ替え、1周で各単語を1回ずつ出題します。途中の取得に失敗した場合は一部だけで開始せず、最初から再読み込みできます。出題順の切り替えは先頭に戻り、向きの切り替えは位置を保って表に戻ります。シャッフルの「もう一度はじめる」は再読み込みして並べ替え直します。学習位置や進捗は保存せず、閉じて開き直すと最初の単語から始まります。

## ページのURL

React RouterのBrowserRouterを使い、次のURLで各画面を直接開けます。

| 画面 | URL |
| --- | --- |
| ログイン・ホーム | `/`（ログイン済みなら`/library`へ） |
| 自分の単語帳 | `/library` |
| JSON追加 | `/library/import` |
| 単語帳の詳細 | `/library/decks/:id` |
| 全画面のカード学習 | `/library/decks/:id/study` |
| 共有設定 | `/library/decks/:id/share` |
| お試しモード | 上記の`/library`を`/demo`に置き換え |
| 公開検索 | `/explore` |
| 公開単語帳の詳細・学習 | `/shared/:id`・`/shared/:id/study` |

検索文字列は`?q=...`、自分の一覧の教材フィルターは`tag`、名前順は`sort=name`に保存します。ブラウザの戻る・進むでも画面と条件を復元します。未ログインで自分の詳細URLを開いた場合、ログイン後にその画面を表示します。存在しない単語帳やページは案内を表示します。以前の`/?demo=1`は`/demo`へ転送します。学習ページの再読み込みでは最初のカードに戻ります。

PagesのSPAフォールバックで、直接アクセスや再読み込みにも`index.html`を返します。`public/404.html`を追加するとこの動作が変わるため、追加する場合は配信ルールも見直してください。

## 公開単語帳を保存する

公開単語帳を開き、**自分の単語帳に保存** を選びます。未ログインの場合は **Googleでログインして保存** から続けられます。保存後は自分の単語帳の詳細を開きます。

英単語・意味・例文・単語タグ・教材タグを、その時点の内容で非公開コピーとして保存します。元の単語帳の変更は自動反映されません。元が非公開・削除になっても保存分は残ります。同じ公開単語帳を再度保存すると既存のコピーを開き、自分自身の単語帳なら元の単語帳を開きます。保存したコピーを削除した後は、元が公開中なら保存し直せます。

コピーはJSON登録と同じ冊数・語数・日次・容量の上限に含まれます。`ALLOW_IMPORTS=false`では新しいコピーも停止します。同時保存は所有者と元IDの一意制約で重複を防ぎ、コピーと利用数の更新をD1の1トランザクションで行います。失敗時は一括して取り消します。

## 単語帳を共有・検索する

1. Googleログイン後、自分の単語帳を開きます。
2. **共有 → 公開して共有する** を選びます。
3. **リンクをコピー** で、`/shared/単語帳ID`のURLを共有できます。リンク先はログイン不要です。
4. **非公開に戻す** と、公開検索・共有ページ・公開単語APIから取得できなくなります。

[公開単語帳を探す](https://azuki.mame-app.com/explore)では、単語帳名・説明・教材名・版・章で検索できます。単語帳を開くと英単語や日本語の意味で検索し、例文を表示できます。教材タグを選んでも関連する単語帳を探せます。

公開されるのは単語帳の内容と教材タグです。所有者ID、Googleの表示名、メールアドレスは公開APIに含めません。新規取り込みは引き続き非公開で、JSONから公開設定を変えることはできません。公開設定の変更と削除は所有者だけが行えます。お試しモードの単語帳は公開できません。

公開一覧は1回20冊、単語は1回50語でページ送りします。検索は100文字以内です。公開用の索引と作成日時・IDのカーソルを使い、所有者用APIと公開APIを分離しています。すべてのAPIレスポンスを`Cache-Control: no-store`にし、取得のたびに現在の公開状態を確認します。

| 操作 | API |
| --- | --- |
| 公開一覧・検索（認証不要） | `GET /api/public/decks?q=...&cursor=...` |
| 公開単語帳（認証不要） | `GET /api/public/decks/:id` |
| 公開単語・検索（認証不要） | `GET /api/public/decks/:id/words?q=...&cursor=...` |
| 公開単語帳を非公開コピーとして保存（ログイン必須） | `POST /api/decks/:id/save` |
| 公開設定の変更（所有者のみ） | `PATCH /api/decks/:id/visibility`（`{"visibility":"public"}`または`private`） |

## 確認・開発

```sh
npm test
npm run build
npm run db:local
npm run dev:api
```

現在の `.env.local` は `VITE_API_BASE_URL=https://azuki-api.mizuno-taiyo-sub.workers.dev` に設定し、ローカル画面も本番API・D1に接続します。通常は `npm run dev` だけで起動できます。同じGoogleアカウントの単語帳を共有し、追加・編集・削除も本番に反映されます。お試しモードのデータはブラウザ内に保存されます。

本番から分離してAPIを開発するときは `.env.local` の `VITE_API_BASE_URL` を空に戻し、`npm run db:local` で準備したうえで、`npm run dev:api`と`npm run dev`を別のターミナルで起動します。ローカルのAPIでも本物のFirebase IDトークンを検証します。無認証でAPIに書き込む開発用の抜け道はありません。ログイン前の画面確認にはお試しモードを使います。

テストではコピーの所有者分離・重複防止・元削除後の維持・上限による取り消し、URLの直接表示と戻る・進む、Googleログイン後の保存導線、公開・非公開の切り替え、匿名閲覧と非公開への復帰、公開検索・ページ送り、JSON検証、ユーザー間のアクセス分離、Google認証トークンの署名・期限・宛先、500語の一括登録、ページ送り、検索、削除と容量集計、上限超過時の取り消しを確認します。D1のSQLは実SQLiteで実行し、パラメーター数と一括クエリ数の制限を再現しています。実Googleログインと本番D1への接続は、アカウント設定後に別途確認します。

### コピーと派生版の公開

保存した単語帳は非公開コピーになり、コピー元の名前とリンクを保持します。そのまま再公開することはできません。単語一覧を開き、「単語・意味・例文を編集」から内容を変更すると、共有画面で派生版として公開できます。公開中の内容を編集すると一度非公開になります。

公開時は単語・意味・例文のSHA-256を比較します。並び順、タイトル、説明、タグ、英単語の大文字小文字、全半角や連続空白だけの違いは新しい内容とみなしません。同じ内容が公開されている場合は409応答と公開中の単語帳へのリンクを返します。同時公開はDBトリガーでも防止します。

検索一覧ではコピー元と派生版を1冊にまとめ、「派生版を見る」から内容の異なる版を表示します。派生版のタイトル・説明・教材タグも検索対象です。既存の同内容コピーは一覧からまとめるだけで、共有URLと保存内容は維持します。コピー元が非公開・削除された場合、その内容は公開せず、残っている公開版を一覧の代表にします。

単語編集は所有者だけができ、入力検証・競合検知・容量制限と非公開化を同一トランザクションで行います。

### 学習開始前の設定

出題順とカードの向きは、カード学習を開始する前に選びます。「次回からこの画面を表示しない」を選ぶと、以後は保存した設定で開始します。ライブラリのプロフィールアイコンから設定を変更でき、チェックを外すと開始前の画面が再び表示されます。設定はブラウザ単位で保存され、Googleアカウントには同期しません。変更した設定は次回の学習開始時に適用されます。


### Google Analytics

測定IDは `G-BS97NCCDPP`（`.env.production` の `VITE_GA_MEASUREMENT_ID`）。本番ビルドかつ `azuki.mame-app.com` の場合だけGoogleタグを読み込みます。ローカル・PagesのプレビューURLでは送信しません。

**公開前の設定**：Google Analyticsの「管理 → データストリーム → 該当のウェブストリーム」で「拡張計測機能」をオフにしてください。手動のページビュー計測と重複する履歴イベント、および検索語・フォーム・リンクの自動取得を防ぎます。`send_page_view: false` だけでは履歴ベースの自動計測は停止しません。設定済みかどうかはコードから確認できません。

ページ遷移は手動で `page_view` を送ります。検索パラメータ、ハッシュ、単語帳ID、実際のページタイトルは送らず、ルートの分類と固定タイトルを使います。ユーザーIDやGoogleアカウント情報は設定しません。Google Signalsと広告パーソナライズ用シグナルも無効にしています。通常のGAのCookie等によるアクセス解析は行われます。公開後はGAのリアルタイム画面で画面遷移を確認してください。


### Cookie選択

初回の案内で「許可する」を選ぶまで、Google Analyticsのタグを読み込みません。選択は `azuki.cookie-choice.v1` にブラウザ単位で保存します。ログイン後、プロフィールから開く設定画面で変更できます。詳細説明は `/privacy` に掲載しています。取り消すとGoogleの計測無効化フラグを設定し、削除可能な `_ga` 系Cookieを削除します。過去に送信した情報の削除ではありません。ローカルでは同意後もアクセス解析を送信しません。

## 単語帳の通報と運営管理

公開単語帳の「この単語帳を通報」から、Googleログイン後に理由・補足を送信します。同一ユーザー・同一単語帳は1件、24時間に5件までです。D1の一意制約とトリガーでも制限し、通報では単語帳の公開範囲を変更しません。

管理画面は `/admin/reports`。設定画面の「運営管理」は、APIで管理権限が確認できたアカウントにだけ表示します。サーバーの `ADMIN_EMAILS` に指定した、Firebaseの署名検証済み・メール確認済み・Googleログインのアカウントだけが閲覧・更新できます。クライアントから指定されたメールや権限は使用しません。

管理画面では未対応・対応済み・対応不要を切り替え、運営だけが読める対応メモを保存します。50件単位でページ送りできます。対象の単語帳が削除されても、通報時のタイトルと対応記録は残ります。対応状況の更新は、単語帳の削除や公開停止を行う操作ではありません。
